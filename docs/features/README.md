# Verex — Feature Designs

Per-feature design docs for the Verex prediction market, in the **Category → Feature → to-do**
structure. This **complements** (does not replace) the roadmap in [`../plan/`](../plan/): the
roadmap is the sequencing/design master doc; this folder breaks the product into feature
categories with actionable to-dos.

Status is keyed to the 10-step roadmap (`../plan/README.md §1.4`): **S1 ✅ · S2 (current) · S3–S10 planned**.
