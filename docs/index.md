# Verex — Documentation

Verex is a prediction market: an on-chain CTF exchange with a hybrid AMM/CLOB, UMA-based
oracle resolution, and account abstraction for onboarding.

This site is served by GitHub Pages from `main:/docs`, so every page below is the current state
of `main`. Links point at the rendered pages; the markdown sources sit in the same paths under
[`docs/`](https://github.com/linked0/verex/tree/main/docs).
