# 컨설팅 가격·전달 모델 참고 + 한국 SME 5개 컨설팅 → SaaS 식별

> 2026-05-27 등록. Verex *제품 자체*가 아니라 Verex 작업을 통해 노출되는
> *가격·전달 모델 패턴*을 컨설팅 사업의 참고로 활용. 첫 5개 한국 SME
> 컨설팅을 끝낸 시점에 SaaS화 가능한 부분을 식별한다.

## 1. Verex 연결

- Verex 자체를 SME에 팔거나 호스팅하지 않음
- Verex 작업 중 드러나는 **가격 모델 패턴**(예: per-market 수수료 vs 구독 vs 트래픽-기반)과 **전달 모델 패턴**(SDK + CLI + 데모 anvil 구성, 운영자 설정 단계, 자체 호스팅 대 매니지드)을 컨설팅 product의 가격·전달 설계에 reuse
- 즉 Verex 코드/아키텍처는 그대로, **business pattern만 추출**

## 2. 행동: 첫 5개 한국 SME 컨설팅

- 5개 진행 — 각 케이스에서 *반복되는 작업 단위*를 기록 (셋업, 통합, 운영, 보고 등)
- 자동화·표준화 가능한 단위를 후보로 누적
- 5번째 종료 시점에 후보 목록을 검토

## 3. 산출 — SaaS화 가능한 부분 식별

5개 case 종료 시:

- 후보 목록을 (a) 자동화 비용, (b) SME가 동일 기능에 지불할 가격, (c) 우리가 운영 가능한 규모 세 축으로 평가
- 1~2개 후보를 SaaS pilot 후보로 선정
- 별도 product/business 결정 doc(`docs/strategy/<date>-saas-pilot-decision.md`) 진입

## 4. 트리거

- **활성화**: 첫 5개 한국 SME 컨설팅 완료 — 또는 진행 중에 동일 패턴이 3 case 이상에서 반복 관찰되면 조기 활성화
- **정지**: 5개 끝나도 의미 있는 SaaS 후보가 없으면 본 트랙 closed로 표시 + 이유 명시 (컨설팅 자체는 별개로 계속)

## 5. 본 doc의 한계

- Verex 코드베이스의 결정 doc이 아님 — 사업 전략 메모
- 정량 분석 없음. 5개 case 누적 후 수치 기반 결정 doc으로 격상
